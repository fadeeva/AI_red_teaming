# AI Red Teaming Portfolio

This repository documents hands-on adversarial ML research, LLM exploitation techniques, and system-level red team exercises.

## Objectives
- Build deep, practical knowledge of adversarial attacks against ML and LLM systems.
- Develop the ability to think like an attacker across the full AI stack: model, data, application, and infrastructure.
- Produce professional-grade red team reports with reproducible exploits and actionable mitigations.
- Bridge the gap between classical cybersecurity and modern AI security.
